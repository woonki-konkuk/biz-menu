메뉴 구조 한눈에 보기

상단 메뉴 6개 · 하위 메뉴는 모두 같은 단계의 탭으로 페이지 안에 표시. 위 헤더에서 직접 클릭해 보세요.

  • 서브페이지 상단의 큰 히어로 배너(사진·문구·브레드크럼) 제거 → 제목 한 줄로 바로 시작
  • 상단 메뉴 마우스오버 드롭다운 제거 → 클릭하면 해당 섹션 페이지로 이동, 하위 메뉴는 페이지 안 제목 아래 탭 메뉴로 표시
  • 3단계 메뉴(졸업요건·장학제도 아래)는 없애고 같은 단계의 탭으로 펼침
  • 학과소개는 통합 단일 페이지(탭 없음), 취업지원도 단일 게시판
  • 교수소개 탭은 분야별로 예시 구성 (현재 사이트의 일반전임·외국인전임·산학협력 구분으로 바꿔도 됨)
  • 이용안내(사이트맵·로그인)는 상단 메뉴에서 빼고 헤더 유틸 링크로 이동
